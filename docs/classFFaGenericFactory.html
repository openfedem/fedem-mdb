Detailed Description

template<class T, class Key = std::string, class ArgType = int>
class FFaGenericFactory< T, Key, ArgType >

Template singelton class defining a general object creation factory.

This class is used for managing methods for creating instances of a varity of classes, such as finite element types, etc. Call back methods creating an instance of a specific type are stored as function pointers in a map with the object type name as lookup key.
