Detailed Description

Class for holding and calculation of checksum value of objects.

The checksum calculation is based on a CRC32 (32-bit Cyclic Redundancy Check) algorithm.

◆ add() [6/12]

void FFaCheckSum::add ( double  e,
int  precision = 0 
)

Adds the checksum of a double value to checksum.

If precision > 0, the value e is rounded to precision significant digits, and the checksum is calculated from the mantissa and exponent separately and then added together. Otherwise (if precision is zero), the last two bytes (7th and 8th) of the double word e is omitted from the checksum calculation.
