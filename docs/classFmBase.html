Detailed Description

Base parent class for the model data structure entries.

Very little functionality is included in this class. It is mostly concerned with the user ID and description, and pointers used for storing objects in the linked lists which constitute the model database.

Author
Jens LIEN

◆ CopyMode

enum FmBase::CopyMode

Enumerator for the different copying modes.

Enumerator
NOTHING 

Don't copy any data fields.

SHALLOW 

Copy all data fields, but not the references.

DEEP_UNRESOLVED 

Also copy references, but leave them unresolved.

DEEP_APPEND 

Also copy and resolve references.

DEEP_REPLACE 

Also copy references, replacing existing ones.

◆ cloneOrConnect()

bool FmBase::cloneOrConnect ( )

Inserts or copies this object into the model database.

This method is used from model file reading, but only for objects that might have been created before reading the model file. If the object to be connected (*this) already exists in the database, all data is copied (cloned) from this object into the found object. This object is then deleted.
