Detailed Description

Class to represent a 3D symmetric tensor.

Tensor layout:

T = {t11, t22, t33, t12, t13, t23}

◆ prinsipalValues() [2/2]

void FFaTensor3::prinsipalValues ( FaVec3 &  values,
FaMat33 &  rotation 
) const

Gets the principal directions and associated values of the tensor.

A valid rotation matrix corresponding to the principal axes of the tensor is calculated. The associated principal values are also found in the corresponding order. If the rotation matrix can't be found, the identity will be returned, along with a vector of HUGE_VAL.
