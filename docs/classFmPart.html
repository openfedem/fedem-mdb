Attaching a triad when having an old triad in the same place.

This is what has to be done in this method:

  • If the triad to attach is a dependent joint triad and the old triad has boundary conditions, inquire if the boundary conditions should be moved to the joint instead.
  • Clone properties from the old triad to the attached one.
  • Erase the old triad.

HOW THE COORDINATE SYSTEMS FOR THE TRIADS ARE CHECKED AND MATCHED

Master = Independent joint triad
Slave  = Dependent joint triad

Old triad                    New triad
---------                    ---------
Master    --- CS check >>--  Master >> if the CSs are the same: OK
Master    ---- XX ----       Slave  (except FreeJoint: same as None->Slave)
Master    -- CS -->          None w/o dirs

Slave     ---- XX ----       Master (except FreeJoint: same as None->Master)
Slave     ---- XX ----       Slave  (except FreeJoint: same as None->Slave)
Slave     -- CS -->          None

None      <-- CS --          Master
None      <-- CS --          Slave
None      -- CS -->          None

Imports FE part data from an external source.

The fileName is here supposed to be a full-path name of an existing file outside the model database. It can be of any of the supported file formats. If conv is specified (i.e., not NULL), it is used to convert the units of all dimensional quantities in the imported file to the current modeling units. If storeRelativePath is true, only the path relative to current model file location is stored in originalFEFile, otherwise the full path is stored.

This method will also create triads at all FE nodes in the imported file that are tagged as external. In addition (but only if autoRefNodeTriads is true), triads will be created at the reference nodes of WAVGM and RGD elements in the model, if no other elements are connected to these nodes. For the WAVGM elements, this will results in additional nodes and elements being created since the WAVGM reference node itslef is a slave node and can not be external, see getNodeAtPoint().

bool FmPart::updateTriadTopologyRefs ( bool  checkUnloaded = true,
char  useOutput = 3 
)

Updates triad to FE node connection after (re)loading the FE model.

This method is supposed to find all triads on this part that are not valid for solving, because they are wrongly positioned or can not be associated with a valid FE node. It is used to keep the model as consistent as possible.

  • If it is a generic or suppressed part:
    • No checking, all triads are valid.
  • If it is a FE part:
    • If no FE data is loaded:
      • Checks that all triads have a FE node assigned.
      • Report those triads that don't.
    • If FE data is loaded:
      • Checks which triads are validly connected to the underlying FE mesh.
      • Updates the FE node number on each triad. Set to -1 if no FE node found.
