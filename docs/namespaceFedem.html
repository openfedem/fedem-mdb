int Fedem::checkReducerFiles ( const FmPart *  part,
bool  needMassMatrix = false,
char  checkingWhich = 'A',
bool  preparingForBatch = false,
unsigned long int  wantCS = 0 
)

Checks the validity of the reduced matrix files of a part.

Parameters
[in]partThe FE part to check matrix files for
[in]needMassMatrixIf true, mass matrix files are needed
[in]checkingWhichFlag indicating which files to check for.
  • 'S': Files needed by the Dynamics Solver only.
  • 'R': Files needed by Stress Recovery only.
  • 'A': Check all files.
[in]preparingForBatchIf true, prepare for batch execution
[in]wantCSExpected checksum value (ignore if zero)
Returns
-1 : Some or all files are missing
0 : Some or all files are either missing or have checksum mismatch
1 : All files are present and with correct checksum
2 : All files are present, but with unknown checksum status
3 : All files are present, but some have incorrect checksum

FmModelMemberBase * Fedem::createUserElm ( int  elmType,
const char *  typeName,
const std::vector< FmTriad * > &  triads,
size_t  nelnod,
FmBase *  subAssembly = NULL 
)

Creates user-defined elements.

Parameters
[in]elmTypeElement type ID
[in]typeNameElement type name
[in]triadsList of triads connected to the created element(s)
[in]nelnodNumber of element nodes for the created element(s)
[in]subAssemblyParent assembly of the created element(s)

If nelnod equals 1, a user-defined element is created for each of the given triads. If nelnod equals 2, a chain of nelnod-1 elements is created connecting the given triads. If nelnod is larger than 2 (and less than or equal to the size of triads), then one user-defined elements is created connected to the first nelnod triads.
