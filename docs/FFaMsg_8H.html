#define ListUI   FFaMsg::getMessager()

Output stream for feedback messages to the user.

This symbol works like an output stream. Use this instead of std::cout and std::cerr when the message is meaningful to the user too (and not only for the developers). A set of output stream operators are defined for various variable types (not documented) which format the value to a std::string which then is passed to FFaMsg::listVt().
