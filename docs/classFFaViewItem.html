Detailed Description

Abstract interface class for list view items.

It also contains some static helpers for sorting view items. The description sorting is case insensitive.

Binary comparison of description strings (implementation of less).

Returns true if the description *i1 precedes that of *i2. Case insensitive comparison. If the strings are equal, the ID of the two objects are compared instead. If either i1 or i2 is NULL, return as if the NULL-pointer is first.
