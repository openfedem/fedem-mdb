Detailed Description

Base class for the FEDEM model database structure.

This class contains the core of the model database structure. It manages FFaField, FFaReference and FFaReferenceList members in derived subclasses, and provides automated I/O, single and multiple guarded pointers.

◆ copy()

bool FFaFieldContainer::copy ( const FFaFieldContainer *  other,
bool  fieldsOnly = false,
bool  unresolve = false 
)

Copies all fields and references from another object into *this.

This method copies all fields, references and reference lists from the supplied FFaFieldContainer object *other into *this.

The big assumption is that the field containers are of the same type, and thus has the same number of references and in the same order.

If fieldsOnly is true only the current field values are copied, whereas the default values, references and reference list are not copied.

If unresolve is true, the references are copied but left unresolved, unless the ID is -1.

void FFaFieldContainer::getReferringObjs ( ObjectVec &  vecToFill,
const std::string &  contextName,
bool  sortOnId = false 
) const

Builds a list of FFaFieldContainer objects referring to *this.

This method gets the list of objects referring to this object with the context contextName. The list is sorted w.r.t. the ID if sortOnId is true. This is needed when the execution order is of importance. If the list is not sorted, the order might be different in two consecutive runs of the same model.

Note
The output array vecToFill is not cleared on entry.
