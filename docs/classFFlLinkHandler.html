Detailed Description

Container class for finite element models.

This class holds the data representing a finite element (FE) part in a FEDEM model, and associated methods for accessing and manipulating it.

◆ findFreeNodeAtPoint()

FFlNode * FFlLinkHandler::findFreeNodeAtPoint ( const FaVec3 &  point,
double  tol,
int  dofFilter = -1 
) const

Searches for a FE node that matches a given point.

This method finds the node with (at least) the given number of DOFs (dofFilter), that matches the specified point. If more than one node match the point, return the node among these that is either a free node or a WAVGM reference node. If more than one such match exist, return the closest node among them.

Todo:
This method does not work well with large tolerances. The tolerance is used as a "all within is coincident". In that regime it actually is ID-dependent which node is returned. It is supposed to prioritize the nodes like this:
  1. Replacement node for a WAVGM reference node
  2. WAVGM reference node
  3. Closest free node But if a free node is found that happens to be closer than a found reference node, the free node will be returned instead. There should be two tolerances in this method: Coincident tolerance and search tolerance. JJS 2009.03.27
