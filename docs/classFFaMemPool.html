Detailed Description

Class to streamline efficient memory allocation.

This class is used to help the programmer to reimplement the operators new and delete for small classes that will be instantiated a lot of times. To use, simply make a static member of FFaMemPool in your class, reimplement the operators new and delete in that class by forwarding the calls to FFaMemPool::doNew() and FFaMemPool::doDelete(), respectively:

#include "FFaLib/FFaPatterns/FFaMemPool.H"
class foo
{
public:
static void* operator new(size_t n) { return ourMemPool.doNew(n); }
static void operator delete(void* p, size_t n) { ourMemPool.doDelete(p,n); }
static void freePool() { ourMemPool.freePool(); }
private:
static FFaMemPool ourMemPool;
};
