Detailed Description

The base class for FFaReferenceList.

When autoSizing is true, the entries in the list are deleted when the object pointed to is deleted. Otherwise, the reference is set to zero.

The context name of a reference list is used when doing topological browsing to know why a reference is referring to a certain FFaFieldContainer object. It is supposed to be set upon initializing when adding the list to the book-keeping in the FFaFieldContainer object it resides in.

◆ eraseReferenceIfNeeded()

void FFaReferenceListBase::eraseReferenceIfNeeded ( FFaReferenceBase *  ref)
private

Removes a reference from the list.

This method is used by FFaReferenceBase to notify this container (which the FFaReferenceBase object is a member of), that it has been zeroed out due to the death of the FFaFieldContainer object it was referring to. Takes the auto-sizing mode into account (see autoSizing), it either does nothing, or deletes the reference.
