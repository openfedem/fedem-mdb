Detailed Description

Fedem link writer. Writes "new" version of the Fedem Link Model files.

Format suggestions:

# - comment string
ENTRYNAME{ID primary_data {additional_data - connections}}

Data: either numerical (integer or float) or attributes with identifiers

Example:

FFT3 { 3 32 22 33 44
{ PTHICK 34 }
{ STRCOATREF 3 T }
{ STRCOATREF 5 B } }
