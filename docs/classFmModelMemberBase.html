Detailed Description

Base class for all model data objects.

This class adds a base ID field to the mechanism objects. This is a unique ID over all objects in the model independent of their type. The class also adds a tag field which can be used for grouping the objects. The class is also derived from FFaListViewItem in addition to FmBase, with functionalities for managing objects in GUI tree views.

◆ resolveBaseIDProblems()

void FmModelMemberBase::resolveBaseIDProblems ( )
static

Resolves the conflicting base ID issues for baseIdProblems.

This method contains the 'BaseId magic created by Jens' (moved from FmDB). It should only be invoked immediately after reading a model from file.

All objects that were not inserted in the base ID map (in FmDB.C file scope), because their base ID already was taken, are now inserted with a new base ID. Usually, the object that was in the way have disappeared due to cloning, etc. It is mostly (only) the "quasi"static objects that are created on demand that are the problems, because they are both created and read from file. Time Sensor, Analysis, Mechanism and Global View Settings.
